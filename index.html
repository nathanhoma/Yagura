Scope rules
ⓘSupports RFC1918 and shared 100.64.0.0/10 ranges, up to 16 CIDRs, 1,024 addresses per CIDR and 4,096 total. A domain includes its subdomains. OR still blocks public IPs; CIDR scanning and DNS resolvers remain limited to saved CIDRs. DNS review and explicit approval are required before a named host can be checked. Saving does not scan.
Host approvals

Discover hosts

Discover only within a saved CIDR. The range is split into at most 16 addresses per check; each completed part is saved. In OR mode, look up one authorized name using internal DNS to quarantine private IPs outside the CIDRs. New IPs stay unverified until internal DNS is reviewed and a host name is explicitly approved.
